# WanderFlow

WanderFlow is a modern iOS travel itinerary planner designed to help you organize your trips effortlessly. Built with SwiftUI and SwiftData, it offers a seamless experience for managing your travel plans, expenses, and locations.

## Features

- **Trip Management**: Create, edit, and organize multiple trips with custom cover colors and dates.
- **Itinerary Planning**: Add detailed daily activities with time and location information.
- **Smart Location Search**: 
  - Search for cities worldwide.
  - Search for specific places (restaurants, landmarks, shops) with automatic bias towards your trip's city.
  - Integrated with Apple Maps for accurate location data.
- **Expense Tracking**: Keep track of your travel spending with support for multiple currencies (CNY, USD, EUR, JPY).
- **Offline Capable**: All data is stored locally using SwiftData, ensuring your plans are accessible anytime.

## Requirements

- iOS 17.0+ 
- Xcode 15.0+ (for development)
- Swift 5.9+

## Tech Stack

- **UI Framework**: SwiftUI
- **Data Persistence**: SwiftData
- **Location Services**: MapKit, CoreLocation
- **Architecture**: MVVM-inspired pattern with declarative UI

# WanderFlow (中文说明)

WanderFlow 是一款现代化的 iOS 旅行行程规划应用，旨在帮助您轻松管理旅行计划。该应用基于 SwiftUI 和 SwiftData 构建，为您提供流畅的体验来管理行程、开销和地点信息。

## 功能特性

- **行程管理**：创建、编辑和整理多个旅行，支持自定义封面颜色和日期。
- **行程规划**：添加详细的每日活动，包含时间和地点信息。
- **智能地点搜索**：
  - 支持全球城市搜索。
  - 搜索特定地点（餐厅、地标、商店），自动优先显示您所在城市的搜索结果。
  - 集成 Apple Maps 以获取准确的地点数据。
- **开销追踪**：记录您的旅行支出，支持多种货币（人民币、美元、欧元、日元）。
- **离线可用**：所有数据均通过 SwiftData 本地存储，确保随时随地可访问您的计划。

## 环境要求

- iOS 17.0+
- Xcode 15.0+ (用于开发)
- Swift 5.9+

## 技术栈

- **UI 框架**: SwiftUI
- **数据持久化**: SwiftData
- **位置服务**: MapKit, CoreLocation
- **架构模式**: MVVM 风格的声明式 UI
